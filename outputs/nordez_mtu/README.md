# Nordez/Guenanten direct-MTU validation outputs

These compact outputs summarize the static direct muscle-tendon-unit benchmark
used in the current manuscript scope.

Dataset:
- Muscle-tendon unit length measurement using 3D ultrasound
- DOI: 10.57745/TBCTLO

Included outputs:
- Multi-subject generic-model summaries for gastrocnemius medialis and lateralis.
- GAS2b personalized-model comparison summaries.
- Per-subject/per-posture JSON comparison files.

Not included:
- Downloaded C3D files, Slicer Markups files, OpenSim IK intermediates, or raw
  dataset mirrors.

Interpretation boundary:
- This is static multi-posture direct-MTU geometric benchmarking.
- It is not dynamic gait validation and not clinical validation.
